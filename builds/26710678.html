  • Q352 · Aircraft before handoff · Previously failed. As host, launch a ten-fighter CAP from the host-owned carrier and wait for takeoff. In Tactical View compare both screens over the same water. Record guest flight marker and rendered aircraft model visibility separately.

  • Q352 · Shared fog · Scout a previously unseen enemy contact. Compare screens at the same moment. Both players should receive the newly detected contact, while enemies outside shared detection stay hidden.
  • Q352 · Map pings · In a remote Steam session, middle-click once as guest and once as host at different landmarks. Verify each click creates one marker at the correct location on both screens. Middle-drag as guest to tilt the camera and verify that no ping appears. Both directions must work from player input.
  • Q352 · Leave Session, host status and reclaim · Previously failed. While the battle is running and the guest owns the assigned carrier, use Esc → Main Menu → Leave Session as guest. Verify the guest reaches the menu without an error. Before reinviting, verify the same host battle keeps running, the host panel says Guest disconnected, exactly one departure appears in the Radio Log, and a host move order to the released carrier executes.
  • Q352 · Fresh invite and reconnect · Previously failed. Keep both games open after departure. Send the same guest a fresh Steam invite and verify the guest rejoins the same battle without a restart, the host panel shows connected, and the guest can issue an order to an assigned ship. If teardown is still in progress, record the message and retry with one fresh invite after it finishes.
