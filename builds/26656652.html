Sea of Steel QA

Steam testing 26656652 · Version 2026.11.13.5

This hotfix supersedes build 26656189.

Reported co-op results

Confirmed: The career host started and created a Steam lobby. The guest joined over SteamSockets on the second attempt. The first attempt was rejected for a network-version mismatch.

Failed — ship handoff: The host could still select handed-off ships and override guest orders. The host accepted 47 of 49 single-ship guest order requests. Retest exclusive guest control and movement on both screens.

Open: Steam invite path from sending through acceptance, shared fog, map pings, and clean disconnect. The host log confirmed a join and did not identify the invite path. The connection ended after timeouts and peer shutdown. The fuel-rate check remains open.

  • Launch a career AO with Host co-op enabled. Verify the game stays running and the Steam lobby becomes ready in Command View.
  • Use two different Steam accounts on separate networks. In the host’s Command View, select Invite Steam Friend below Overview | Fit Map and choose the guest. Have the guest accept through the Steam overlay. Confirm the guest sees connection feedback and joins the battle. If the button is missing or the invite picker does not open, record which step stopped you.
  • In Command View, hand a ship to the guest. Verify a guest move order works on both screens. Try issuing a host order to the same ship, both alone and in a mixed selection. The ship should follow guest orders until the host explicitly reclaims it.
  • Compare fog and revealed areas on both screens. Send a map ping and confirm it appears for the other player.
  • Have the guest disconnect normally. Check the host sees the status change and can continue playing.
  • Bring a ship that needs fuel within 50 m of a supplied Fleet supply ship. Stop both ships and let the simulation run. Measure fuel gained per simulation second before either ship hits a stock limit, and verify it is five times the prior build’s rate under the same conditions.
